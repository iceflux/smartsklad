Куда бот отправляет уведомления о заказах (один получатель).

Пусто — берётся SMTP_HOST из файла .env на сервере. Пока поле пустое, .env не отключается: заполненное значение перекрывает его, очищенное — снова уступает ему. Это сделано, чтобы работающее настройками машина не перестала отправлять после переезда настроек в интерфейс.

Целое от 1 до 65535. Пусто — SMTP_PORT из .env, а тот 587.

Пусто — сервер без входа. Значение из .env берётся, только если это поле пустое.

Пустое поле — оставить прежний пароль, а не стереть его: вводить пароль заново при каждой правке адреса не нужно. {% if smtp_password_mask %}Сейчас: {{ smtp_password_mask }}. {% endif %}Сам пароль не показывается и в журнале попадает только замаскированным.

Адрес в заголовке «От кого». Пусто — SMTP_FROM из .env; письмо уйдёт с пустым отправителем, и почтовый сервер его, скорее всего, отвергнет.

Из этих символов генерируется пароль нового пользователя в форме «Создать пользователя».
